# Original 2023 prototype

This directory preserves the complete implementation from the repository's
original 2023 commit. It is retained as provenance and is intentionally not the
active package.

The original prototype explored a creative encoder → linear latent operator →
decoder idea for nonlinear pendulum prediction. The portfolio edition at the
repository root repairs the data contract, objective, evaluation, packaging,
and scientific claims while keeping that original instinct visible.

For the exact untouched snapshot, use the Git tag `prototype-2023`.
